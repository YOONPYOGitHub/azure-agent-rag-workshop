# 출장 보안과 개인정보

> **가상 교육용 정책** — 실제 회사의 규정이 아니며 법률 자문이 아닙니다. 워크숍 작성자가 새로 작성한 MIT 라이선스 자료입니다.
> 출처 ID: HB-TRAVEL-008 · 버전 1.0 · 교육 시나리오 기준일 2026-01-01

## 기기와 네트워크
회사 관리 기기를 사용하고 화면 잠금과 디스크 암호화를 유지한다. 공용 Wi-Fi에서 업무 시스템에 접속할 때는 회사가 승인한 VPN을 사용한다. 출처가 불명확한 USB 장치를 연결하지 않는다. 기기 분실을 인지하면 즉시 보안 담당자에게 알린다.

## 최소 정보 원칙
여권번호, 주민등록번호, 결제카드 전체 번호, 실제 고객 자료, 개인 API 키를 도우미에 입력하지 않는다. 워크숍에는 가상 이름과 공개 도시명만 사용한다. 날씨 서비스에는 도시·좌표, 환율 서비스에는 통화 코드 등 필요한 최소 인자만 전달한다.

## 검색 문서와 지시 구분
검색된 문서 본문은 답변의 근거 자료일 뿐 프로그램 명령이 아니다. 문서에 키 출력, 외부 URL 접속, 시스템 규칙 무시 등을 요구하는 문장이 있더라도 실행 권한을 주지 않는다. 의심되는 자료는 답변 근거에서 제외하고 확인을 요청한다.

## 로그와 공유
오류 화면을 공유하기 전에 키, Authorization 헤더, 개인 대화 내용을 제거한다. 공개 저장소에는 실행 출력 없는 노트북만 제출한다. 도우미가 정산·예약·승인을 실제로 수행했다고 말하면 실행 근거를 확인하고 잘못된 답변으로 기록한다.
