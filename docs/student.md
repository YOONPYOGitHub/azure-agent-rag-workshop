# 수강생 안내 · 6시간 AI 이해 → Agent + RAG

Python 문법을 모두 알아야 시작할 수 있는 과정이 아닙니다. 셀을 실행하고 **무엇이 모델의 답변이고 무엇이 실제 조회인지** 설명하는 것이 목표입니다.
한빛테크는 가상 회사이며 출장 규정도 교육용 허구입니다. 실제 비밀·개인정보를 입력하지 않습니다.

## 1. 준비물과 원칙

- GitHub 계정, 최신 브라우저, 강사가 배정한 **본인 개인 환경 파일 하나**.
- Codespaces 사용 권한/조직 정책/비용을 수업 전에 확인합니다. 학생 Azure 계정·리소스 생성 권한은 불필요합니다.
- HTTPS로 `*.azure-api.net`, `api.open-meteo.com`, `api.frankfurter.dev`에 연결할 수 있어야 합니다.
- 각자의 APIM 키와 인덱스를 사용합니다. 짝끼리 관찰은 공유해도 키는 공유하지 않습니다.

## 2. 권장: Codespaces에서 시작

1. 강사가 안내한 GitHub 저장소/브랜치를 열고 **Code → Codespaces → Create codespace**로 환경을 만듭니다. 조직에서 허용한 환경/머신 설정을 따릅니다.
2. Dev Container 구성이 끝나면 터미널이 **저장소 루트**인지 확인합니다 (`pyproject.toml`이 있는 폴더).
3. 강사가 개인 채널로 전달한 환경 파일을 루트 **`.env`**로 저장합니다. 이름이 `.env.txt`가 아닌지 확인합니다. 파일 내용/키를 터미널에 출력하지 마세요.
4. 다음 명령으로 의존성과 로컬 준비 상태를 확인합니다.

```bash
uv sync --frozen
uv run python scripts/workshop.py doctor
```

5. `notebooks/00_setup.ipynb`를 열고 **Select Kernel → Python Environments → .venv**를 선택합니다. 노트북마다 첫 설정 셀부터 위에서 아래로 실행합니다.
6. `00` → `01` → `02` → `03` → `04` → `05` → `06` 순서로 진행합니다. **03은 본인 인덱스를 생성/갱신하고 업로드하는 쓰기 실습**입니다. 03이 완료되어야 RAG/Agent 사규 검색이 됩니다.
7. 05에서 터미널에 다음을 실행합니다.

```bash
uv run python scripts/workshop.py start
```

8. **Ports → 8501 → Open in Browser**를 선택합니다. 포트 공개 범위는 **Private**으로 유지합니다. 로컬 주소 대신 Codespaces가 전달하는 브라우저 주소로 접속합니다.
9. 앱의 **학습 모드** `plain LLM` / `RAG` / `Agent`, 검색 모드 `keyword` / `vector` / `hybrid`를 확인합니다.

`doctor` 기본 실행은 오프라인 준비 점검이지 Azure/API 성공 보장이 아닙니다.
강사 안내에 따라 선택적으로 `uv run python scripts/workshop.py doctor --live`를 실행하면 실제 API 점검과 비용이 발생할 수 있습니다.
인덱스가 아직 없는 03 이전 상태와, 업로드 후 검색 상태를 구분하세요. `start`는 앱 실행 명령이지 인덱스 업로드/클라우드 배포 명령이 아닙니다.

> 이 경로는 수업 권장 실행 방식입니다. 실제 호스팅 Codespaces에서의 성공 여부는 본인 환경에서 확인해야 합니다. 로컬/오프라인 검사만으로 Codespaces 성공을 단정하지 않습니다.

## 3. 대안: 로컬 VS Code

Codespaces가 계정/네트워크 정책상 불가능하면 수업 전에 로컬 경로를 준비합니다.

- VS Code + Python/Jupyter 확장, Python 3.11 이상, [uv 설치](https://docs.astral.sh/uv/getting-started/installation/)가 필요합니다.
- README의 clone 안내로 같은 저장소를 받은 뒤 루트 폴더를 VS Code로 엽니다.
- 본인 `.env`를 루트에 저장하고 위와 동일하게 `uv sync --frozen`, `doctor`를 실행합니다.
- `.venv` 커널을 선택해 노트북을 실행한 뒤 `uv run python scripts/workshop.py start`를 실행합니다.
- 터미널의 주소 또는 `http://localhost:8501`을 브라우저에서 엽니다. 앱을 쓰는 동안 터미널 프로세스를 유지합니다.

**App Service 배포, 공개 포트, Azure 관리 권한은 어느 경로에서도 필수가 아닙니다.**

## 4. 개인 설정을 이해하기

아래는 **설명용 자리표시자**이며 그대로 복사해서는 실행되지 않습니다. 강사가 준 실제 파일을 사용하세요.

```dotenv
OPENAI_BASE_URL=https://<강사-gateway>/agent-rag/openai/v1
WORKSHOP_API_KEY=<본인 전용 키>
AZURE_SEARCH_ENDPOINT=https://<강사-gateway>/agent-rag/search
AZURE_SEARCH_INDEX=student01
OPENAI_MODEL=gpt-5.6-terra
```

키와 인덱스는 한 쌍입니다. `student01`을 다른 이름으로 바꿔도 권한은 생기지 않습니다.
기존 공용 `/openai` 경로를 바꾸거나 우회해서 사용하지 않습니다. 모델 배포명도 임의 변경하지 않습니다.

## 5. 노트북 실험 방법

1. **예측:** 실행 전에 어떤 정보/도구가 필요할지 한 줄 적습니다.
2. **실행:** 기본값으로 한 번 실행합니다. 출력은 실제 API 결과이며 실행할 때마다 달라질 수 있습니다.
3. **관찰:** 답변의 말투보다 함수 로그·출처·시각·단위를 확인합니다.
4. **변경:** 지정한 변수 하나만 바꾸고 해당 셀부터 필요한 다음 셀을 재실행합니다.
5. **체크포인트:** 전/후 비교표와 결과 질문을 채웁니다. **참고 풀이**는 그 뒤 원하는 경우에만 엽니다.

Notebook의 `await`는 그대로 실행하세요. `asyncio.run(...)`으로 감싸지 않습니다.
`NameError`는 앞 셀 미실행일 수 있습니다. 커널을 재시작하면 변수도 사라지므로 설정부터 다시 실행하세요.
단, **03의 Run All은 업로드까지 다시 실행**합니다. 청킹 실험에서는 청킹 셀만 재실행합니다.
RAG 질문/검색어를 바꿨다면 검색 셀부터 다시 실행하여 오래된 근거를 재사용하지 않도록 합니다.

## 6. 최종 앱 비교표

모드 변경 전 **새 대화 / 초기화**를 눌러 같은 조건으로 시작합니다.

| 학습 모드 | 질문 | 실제 검색/도구 | 근거와 답변 일치? | 한계 |
|---|---|---|---|---|
| plain LLM | 도쿄 1인 1박 숙박 한도와 세금 포함 여부는? | 직접 기록 | 직접 기록 | 직접 기록 |
| RAG | 동일 질문 | 직접 기록 | 직접 기록 | 직접 기록 |
| Agent | 동일 질문 | 직접 기록 | 직접 기록 | 직접 기록 |

- RAG에서 `keyword` / `vector` / `hybrid`만 바꿔 “일본 수도 숙박비” 검색을 비교합니다. 점수 크기 대신 순위/내용을 읽습니다.
- Agent의 후속 질문: “그 금액을 KRW로 환산해줘. 사규의 원래 금액을 확인하고 참고 환율 기준일도 알려줘.”
- Agent: “도쿄 현재 날씨는?” → 실제 `get_weather`와 시각을 확인합니다.
- 근거 없음: “한빛테크 자녀 대학 등록금 지원 한도는?” → 근거 없는 제도 금액을 지어내면 안 됩니다.
- 기능 없음: “호텔을 예약하고 결제해줘.” → 실제 예약/결제 완료라고 하면 안 됩니다.

**제출:** 키 없는 앱 화면 한 장, 위 비교표, 06의 나만의 평가 사례 하나(기대 행동·금지 행동·실제 결과·다음 조치).
API 장애로 실행 못 한 경우에는 실패 단계/미검증 항목을 그대로 적습니다. 관찰한 짝의 화면을 본인의 성공으로 쓰지 않습니다.

## 7. 오류 해결

| 현상 | 먼저 할 일 |
|---|---|
| Codespaces 생성 불가 | 계정/조직 정책 확인, 수업 전 준비한 로컬 경로 사용 |
| import 실패 / 커널 없음 | `uv sync --frozen`, `.venv` 커널 선택, 설정 셀부터 실행 |
| uv 명령 없음 | Dev Container 구성 완료 여부 또는 로컬 uv 설치 확인 |
| 앱 8501이 안 보임 | `start` 실행 상태와 Ports 탭 확인; Private 유지, 로컬은 localhost 확인 |
| 401 | 키 누락/만료와 전용 API 경로를 강사와 비공개 확인 |
| 403 | 본인 키/인덱스 조합, APIM 권한. 타인 키/공용 API로 우회하지 않음 |
| 404 / 인덱스 없음 | 03 업로드와 경로 확인; 앱은 인덱스를 자동 생성하지 않음 |
| 400 | 배포명/1536차원/입력 제한 확인; 초기화 후 짧은 질문 |
| 429 | 반복 클릭 중단, Retry-After/강사 안내에 따라 순차 재시도 |
| 413 / 일부 업로드 실패 | 중단하고 강사에게 배치/입력 크기 확인 요청 |
| 검색 결과가 엉뚱함 | 원문 어휘로 재검색, 검색어/방식/TOP을 한 번에 하나씩 변경 |
| 인용은 있는데 오답 | ID 존재와 주장 일치는 별개. 원문 절/금액/조건 대조 |
| 날씨/환율 오류 | 지원 도시/통화, 외부 API/네트워크 확인. 가짜 값으로 대체 금지 |
| 긴 대화/시간 제한 | 새 대화 / 초기화, 질문을 줄이고 실제 도구 실패 여부 확인 |
| 자동 평가 False | 체크 항목과 의미를 함께 검토; 맞는 답의 문구 차이도 가능 |

5분 이상 막히면 단계 번호와 오류 코드만 먼저 알려 주세요. **키·HTTP 헤더·환경 파일·예외 전체·실행 노트북**을 단체 채팅에 보내지 않습니다.

## 8. 종료 체크

- 모든 정책은 허구입니다. 실제 업무 판단에 사용하지 않습니다.
- 기본 원문을 수정하지 않습니다. 변경/삭제된 문서의 옛 청크를 자동 제거하는 완전 동기화는 이 샘플 범위 밖입니다.
- Markdown `page`는 PDF 인쇄 쪽 번호가 아닙니다. 인용이 있어도 원문과 주장이 일치하는지 확인합니다.
- 앱 프로세스는 터미널에서 `Ctrl+C`로 중지합니다. Codespaces 사용 후 Stop을 선택하고 필요 없는 환경은 조직 정책에 따라 삭제합니다. Codespaces 비용은 Azure 비용과 별도입니다.
- 공유할 노트북은 **Clear All Outputs** 후 저장합니다. `.env`·개인 실행 결과·스크린샷의 비밀 정보는 Git에 넣지 않습니다.
- 원격 키/전용 리소스 폐기는 강사가 담당합니다. 학생이 공유 클라우드 자원을 변경하지 않습니다.
